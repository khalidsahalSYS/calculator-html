# حاسبة

مشروع آلة حاسبة بسيطة باللغة العربية، مبني باستخدام HTML وCSS وJavaScript في ملف واحد.

## المميزات

- العمليات الحسابية الأساسية: الجمع والطرح والضرب والقسمة.
- النسبة المئوية، حذف آخر رقم، ومسح العملية.
- إدخال الأرقام من لوحة المفاتيح أو باستخدام أزرار الآلة الحاسبة.
- تصميم متجاوب بواجهة عربية من اليمين إلى اليسار.

## التشغيل

افتح ملف `index.html` مباشرةً في متصفح الويب. لا يحتاج المشروع إلى تثبيت أو إعداد إضافي.

## اختصارات لوحة المفاتيح

- `0`–`9`: إدخال الأرقام
- `.`: فاصلة عشرية
- `+`، `-`، `*`، `/`: العمليات الحسابية
- `Enter` أو `=`: حساب النتيجة
- `Backspace`: حذف آخر رقم
- `Escape`: مسح الكل
